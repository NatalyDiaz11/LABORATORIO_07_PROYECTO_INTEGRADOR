# Modelos UML - Laboratorio 5

## Proyecto
Khanauky

## Contenido

En esta carpeta se almacenan los modelos UML desarrollados para el Laboratorio 5.

### Archivos

- `diagrama-clases-khanauky.drawio`
- `diagrama-clases-khanauky.png`
- `secuencia-atender-pedido.drawio`
- `secuencia-atender-pedido.png`
- `diagrama-paquetes-khanauky.drawio`
- `diagrama-paquetes-khanauky.png`

## Descripción

### Diagrama de clases

Representa las principales clases del sistema Khanauky, sus atributos, operaciones, relaciones y multiplicidades.

### Diagrama de secuencia

Representa la interacción entre los participantes y componentes involucrados en el caso de uso CU-002 Atender pedido.

### Diagrama de paquetes

Organiza las clases principales del sistema en módulos relacionados con clientes, pedidos, inventario, almacén y producción.

## Formatos

Los archivos `.drawio` contienen los modelos editables.

Los archivos `.png` permiten visualizar los diagramas directamente desde el repositorio.
