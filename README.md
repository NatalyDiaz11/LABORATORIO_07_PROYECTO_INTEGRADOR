# Khanauky - Proyecto Integrador

## Descripción del proyecto

Khanauky es un proyecto académico de Ingeniería de Software orientado al análisis, diseño, modelado y documentación de los principales procesos de una empresa dedicada a la producción y venta de agua tratada y hielo.

El proyecto integra técnicas de ingeniería de requisitos, modelado UML, metodologías ágiles, RUP, trazabilidad y gestión del cambio.
