# Khanauky - Proyecto Integrador

Proyecto académico de Ingeniería de Software orientado al análisis, diseño y organización de los procesos principales de Khanauky mediante RUP y UML.

## Iteración actual

ITER-1 - Fase de Inicio

## Objetivo de la iteración

Definir el alcance del sistema, organizar los artefactos iniciales, identificar riesgos y modelar el proceso crítico Atender pedido.

## Artefactos de ITER-1

- Documento de Visión v1.
- Roadmap RUP.
- Matriz fase-artefacto.
- Diagrama de actividad del proceso Atender pedido.
- Glosario.
- Checklist de coherencia.
- Tabla de riesgos.
- Plantilla de revisión por pares.
- Convenciones del proyecto.
