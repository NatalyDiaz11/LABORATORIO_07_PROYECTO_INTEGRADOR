# SRS - Khanauky

## Requisitos funcionales

| ID | Requisito |
|---|---|
| REQ-001 | El sistema debe permitir registrar y consultar información de clientes. |
| REQ-002 | El sistema debe permitir registrar y gestionar pedidos. |
| REQ-003 | El sistema debe permitir consultar y actualizar el stock de productos y generar una alerta para Almacén cuando la cantidad disponible quede por debajo del stock mínimo definido. |
| REQ-004 | El sistema debe permitir registrar y consultar la información de producción asociada a los pedidos. |
| REQ-005 | El sistema debe permitir consultar existencias y registrar las salidas de almacén asociadas a los pedidos. |
| REQ-006 | El sistema debe permitir consultar el estado de los pedidos. |

## Observación

Estos requisitos representan la línea base funcional del sistema antes de aplicar el cambio controlado del Tema 7.
