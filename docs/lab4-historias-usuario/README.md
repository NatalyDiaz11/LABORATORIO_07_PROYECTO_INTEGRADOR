# Laboratorio 4 - Historias de usuario en metodologías ágiles

## Proyecto
Khanauky

## Propósito

En este laboratorio se aplican historias de usuario al proyecto Khanauky para representar las necesidades de los usuarios desde una perspectiva ágil.

Las historias serán complementadas con criterios de aceptación, una Definition of Done y técnicas de priorización.

## Contenido

- Historias de usuario.
- Criterios de aceptación en formato Gherkin.
- Definition of Done.
- Priorización mediante MoSCoW.
- Priorización mediante técnica de 100 puntos.
- Sesión de refinamiento.
- Definición del Sprint.
- Checklist de validación.
- Conclusiones.

## Relación con los laboratorios anteriores

Los requisitos y casos de uso definidos en los Laboratorios 1, 2 y 3 sirven como base para redactar las historias de usuario del proyecto Khanauky.
