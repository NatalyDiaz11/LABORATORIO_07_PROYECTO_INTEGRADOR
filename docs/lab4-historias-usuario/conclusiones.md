# Conclusiones - Laboratorio 4

## Conclusión 1

El uso de historias de usuario permitió representar las funcionalidades del sistema Khanauky desde la perspectiva de los usuarios, facilitando la comprensión de qué se necesita desarrollar y cuál es el beneficio esperado.

## Conclusión 2

Los criterios de aceptación en formato Gherkin ayudaron a reducir la ambigüedad de las historias, ya que permiten definir claramente las condiciones que deben cumplirse antes de considerar una funcionalidad como terminada.

## Conclusión 3

La aplicación de MoSCoW y la técnica de 100 puntos permitió justificar la prioridad de las historias y seleccionar de manera ordenada las funcionalidades que deben formar parte del primer Sprint.
