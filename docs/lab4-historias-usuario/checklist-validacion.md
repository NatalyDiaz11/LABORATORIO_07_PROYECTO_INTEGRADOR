# Checklist de validación - Laboratorio 4

## Proyecto
Khanauky

Se revisaron las historias de usuario, sus criterios de aceptación, la priorización y la planificación del Sprint.

## Checklist

- [x] Las historias de usuario siguen el formato Como / quiero / para.
- [x] Se definieron cinco historias de usuario.
- [x] Cada historia tiene criterios de aceptación en formato Gherkin.
- [x] Los criterios de aceptación utilizan Dado que / Cuando / Entonces.
- [x] Se definió una Definition of Done aplicable a todas las historias.
- [x] Se aplicó la técnica de priorización MoSCoW.
- [x] Se aplicó una segunda técnica de priorización mediante 100 puntos.
- [x] Se justificó el orden de prioridad de las historias.
- [x] Se realizó una sesión de refinamiento con roles definidos.
- [x] Se seleccionaron las historias correspondientes al Sprint 1.
- [x] Se identificaron las historias que permanecen en el Product Backlog.

## Resultado

La revisión permitió comprobar que las historias de usuario de Khanauky están correctamente formuladas, cuentan con criterios de aceptación y han sido priorizadas mediante dos técnicas.

La sesión de refinamiento permitió definir un primer Sprint coherente con las necesidades principales del proyecto.
