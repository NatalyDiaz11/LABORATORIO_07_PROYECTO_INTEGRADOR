# Definition of Done - Khanauky

## Propósito

La Definition of Done establece las condiciones mínimas que debe cumplir una historia de usuario antes de considerarse terminada.

## Criterios

Una historia de usuario se considera terminada cuando:

- La funcionalidad ha sido implementada.
- Cumple con todos sus criterios de aceptación.
- La información relacionada se encuentra documentada.
- La funcionalidad ha sido revisada por al menos un integrante del equipo.
- No genera errores en funcionalidades que ya estaban operativas.
- La interfaz o comportamiento esperado puede ser comprobado mediante evidencia o prueba.
- Los cambios relacionados han sido registrados mediante commits descriptivos.
- Si corresponde, la documentación del requisito, caso de uso o interfaz ha sido actualizada.

## Aplicación al proyecto Khanauky

Esta Definition of Done será utilizada como referencia para revisar las historias de usuario definidas en el Laboratorio 4.

Por ejemplo, HU-03 Consultar y actualizar stock no podrá considerarse terminada si la funcionalidad actualiza cantidades pero no cumple las validaciones definidas o genera inconsistencias en el stock.

## Resultado

La Definition of Done permite que el equipo tenga un criterio común para decidir cuándo una funcionalidad está realmente completada y lista para ser considerada dentro de una iteración.
