# Laboratorio 1 - Requerimientos funcionales y no funcionales

## Proyecto
Khanauky

## Propósito
En este laboratorio se identifican y clasifican los requerimientos funcionales y no funcionales del sistema Khanauky.

Los requerimientos funcionales describen las acciones que el sistema debe realizar, mientras que los requerimientos no funcionales establecen cualidades, restricciones o condiciones que el sistema debe cumplir.

## Contenido
- Requerimientos funcionales.
- Requerimientos no funcionales.
- Clasificación mediante ID, tipo y descripción.

## Evidencia
Los requerimientos definidos en este laboratorio servirán como base para los siguientes laboratorios del proyecto.
