# Laboratorio 3 - Modelado de casos de uso

## Proyecto
Khanauky

## Propósito
En este laboratorio se modelan los principales casos de uso del sistema Khanauky a partir de los requisitos identificados previamente.

Se definen los actores, el alcance del módulo, los casos de uso principales, sus relaciones, reglas de negocio, validaciones y excepciones.

## Contenido
- Alcance del módulo.
- Actores y objetivos.
- Casos de uso.
- Especificación detallada de casos de uso.
- Reglas de negocio.
- Diagramas de actividad.
- Prototipo y flujo de navegación.
- Checklist de consistencia.

## Relación con los laboratorios anteriores
Los requisitos identificados en los Laboratorios 1 y 2 sirven como base para definir los casos de uso del sistema Khanauky.
