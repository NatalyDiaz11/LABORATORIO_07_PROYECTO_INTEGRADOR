# Laboratorio 2 - Elicitación y análisis de requisitos

## Proyecto
Khanauky

## Propósito
En este laboratorio se aplican técnicas de elicitación, análisis y validación de requisitos al proyecto Khanauky.

Se identifican las necesidades de los stakeholders, se organizan los requisitos del sistema y se analizan posibles conflictos entre los interesados.

## Contenido
- Estructura inicial del SRS.
- Técnicas de recolección de información.
- Identificación de stakeholders.
- Catálogo de requisitos.
- Validación de requisitos.
- Resolución de conflictos.
- Buyer Persona.
- Mapa de empatía.
- Story Map.

## Relación con el Laboratorio 1
Los requerimientos identificados en el Laboratorio 1 sirven como base para desarrollar el análisis y la elicitación del Laboratorio 2.
