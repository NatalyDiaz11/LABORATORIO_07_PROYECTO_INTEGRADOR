# SRS inicial - Khanauky

## 1. Introducción

### 1.1 Propósito

El propósito del sistema Khanauky es apoyar la gestión de clientes, pedidos, producción, almacén y stock de una empresa dedicada a la producción y venta de agua tratada y hielo.

El sistema busca centralizar la información operativa y reducir errores derivados de registros manuales o información dispersa.

### 1.2 Usuarios principales

Los principales usuarios del sistema son:

- Vendedor.
- Personal de Producción.
- Personal de Almacén.
- Administrador o responsable del negocio.

---

## 2. Descripción general

Khanauky permitirá registrar y consultar información relacionada con clientes y pedidos, controlar las existencias de productos, registrar información de producción y almacén, y consultar el estado de los pedidos.

El sistema servirá como apoyo para mantener la información organizada y facilitar el seguimiento de las operaciones del negocio.

---

## 3. Requisitos específicos

### 3.1 Requisitos funcionales

| ID | Requisito |
|---|---|
| RF-01 | El sistema debe permitir registrar y consultar información de los clientes. |
| RF-02 | El sistema debe permitir registrar pedidos indicando el cliente, los productos y las cantidades solicitadas. |
| RF-03 | El sistema debe permitir consultar y actualizar el stock disponible de los productos. |
| RF-04 | El sistema debe permitir registrar y consultar información de producción asociada a los pedidos. |
| RF-05 | El sistema debe permitir consultar las existencias y registrar las salidas de almacén asociadas a los pedidos. |
| RF-06 | El sistema debe permitir consultar y actualizar el estado de los pedidos. |

### 3.2 Requisitos no funcionales

| ID | Requisito |
|---|---|
| RNF-01 | El sistema debe presentar una interfaz clara y comprensible para los usuarios. |
| RNF-02 | El sistema debe permitir el acceso a la información únicamente a usuarios autorizados. |
| RNF-03 | El sistema debe mantener la consistencia de la información durante las operaciones de registro y actualización. |
| RNF-04 | El sistema debe mantener disponible la información necesaria durante las operaciones habituales del negocio. |
