# Laboratorio 5 - Modelado conceptual con diagramas de clases UML

## Proyecto
Khanauky

## Propósito

En este laboratorio se desarrolla el modelado conceptual del sistema Khanauky mediante diagramas de clases UML.

Se identifican las clases principales del sistema, sus atributos, operaciones, relaciones y multiplicidades.

También se analiza la relación entre los requisitos y las clases, se aplica un refactor para mejorar la cohesión y el acoplamiento y se elaboran diagramas complementarios para verificar la consistencia del modelo.

## Contenido

- Identificación de clases.
- Atributos y operaciones.
- Relaciones y multiplicidades.
- Matriz requisito-clase.
- Diagrama de clases UML.
- Diagrama de secuencia.
- Refactor por cohesión y acoplamiento.
- Diagrama de paquetes.
- Checklist de consistencia.

## Relación con los laboratorios anteriores

Los requisitos, casos de uso e historias de usuario definidos en los Laboratorios 1 al 4 sirven como base para identificar las clases necesarias dentro del sistema Khanauky.

El modelado desarrollado en este laboratorio también servirá posteriormente como base para la trazabilidad trabajada en el Laboratorio 7.
